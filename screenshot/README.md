# Danh sách các ảnh chụp màn hình minh chứng (Screenshots)

Hãy chụp lại kết quả các bước và lưu vào thư mục này:

1. `01-create-user.png`: Lệnh tạo user `tranthikhanhuyen`, cấp quyền sudo và kết quả lệnh `id tranthikhanhuyen`.
2. `02-install-software.png`: Kết quả cài đặt gói và kiểm tra trạng thái Nginx: `systemctl status nginx`.
3. `03-git-commits.png`: Lịch sử commit trên Git: `git log --oneline`.
4. `04-clone-permission.png`: Kết quả `git clone`, phân quyền `ls -ld` (755 cho folder) và `ls -l` (644 cho file).
5. `05-nginx-test.png`: Kết quả `sudo nginx -t` và `curl -I http://localhost`.
6. `06-ufw-status.png`: Cấu hình tường lửa và kết quả `sudo ufw status verbose`.
7. `07-browser-result.png`: Giao diện website hiển thị trên trình duyệt.
